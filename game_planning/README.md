## Главные цифры (Base-сценарий)

- Разработка и запуск: **$74 496** из $75 000 (+10% резерв внутри)
- Год 1: 120 000 игроков, 3 600 платящих, 8 B2B-лицензий → **$39k** валовой выручки
- За 3 года валовая выручка **$194k**: 45% платные сценарии, 52% B2B, 3% реклама
- Окупаемость на **3-м году**, ROI за 3 года **+32%**
- Low-сценарий не окупается, High окупается в первый год. Это нормально: показывает риск
